# Politique de confidentialité — MediaLibre

Ce dépôt ne contient que la politique de confidentialité publiée de l'application Android
**MediaLibre** (`com.medialibre.app`), telle que référencée par sa fiche Google Play.

- Page publiée : <https://zeptoniator.github.io/medialibre-privacy/>
- Texte source : [`index.md`](index.md)

Le texte est dérivé de l'inventaire des données du dépôt applicatif
(`privacy/data-inventory.md`), lui-même établi par lecture du code : entités Room,
traducteurs de synchronisation et règles Firestore déployées. Les deux documents et la
déclaration Data Safety de Google Play doivent toujours dire la même chose.

Le code de l'application vit dans un dépôt privé distinct. Toute modification
substantielle de la politique est publiée ici avec une nouvelle date de mise à jour.
